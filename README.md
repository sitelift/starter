# SiteLift client starter

Clone-per-client template for [SiteLift.net](https://sitelift.net) agentic builds.

**Stack:** Astro · TypeScript · Tailwind · MDX

## New project

1. Clone this repo for the client
2. Fill in [`client.md`](./client.md) — business, contacts, brand, preferences, progress
3. `npm install && npm run dev`
4. Add pages in `src/content/pages/` (see [`AGENTS.md`](./AGENTS.md))

## Commands

| Command         | Action              |
| --------------- | ------------------- |
| `npm run dev`   | Start dev server    |
| `npm run build` | Production build    |
| `npm run preview` | Preview build     |

## Agent workflow

See [`AGENTS.md`](./AGENTS.md). Agents use `client.md` for all project context and update it as they go.
